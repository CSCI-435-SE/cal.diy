## Assistant <sup>9/18/2026, 12:23:56 AM</sup>

Good, they're in sync. I'll explain the root cause, then check out the branch and apply the fix locally.

The bug: the PR changed the hint coloring to key off `formState.dirtyFields[fieldName]` instead of `formState.isSubmitted`. React Hook Form's `dirtyFields` flag, once set true (the value differs from its default even briefly), does **not** reset to `false` when the field is cleared back to empty — it stays `true`. So "type a character, then delete it" leaves the field dirty but empty, and every hint renders as a failing red "X" instead of returning to the neutral gray state.
