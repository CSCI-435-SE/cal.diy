2. What is one thing you learned about the codebase or about software engineering practice?
The biggest thing that I learned about the software engineering practice through this class is using git collaboratively. This is my first long-term group software project - in the past I had done hackathons but we didn't use Git, we used VSCode Liveshare - and the first time I have had to use Git regularly. Before this class, I did not use branches, I did not know what a pull request was - I generally just worked by myself and just pushed to main. While I definitely don't understand everything, I can checkout a remote branch, run a teammate's code on my machine and review it, something that I did not know how to do earlier. In the process of using git, I now have a better idea of how things like branches and checking out work, which I think will be useful for the future.
