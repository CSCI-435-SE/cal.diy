## What problem does DBeaver solve?

When one is working on a large database, it quickly becomes impractical to use database commands for browsing the database contents. (ie if you want to grab a specific user, `SELECT * FROM users WHERE user_id=881c9452-a9b4-4c7a-bcfe-a9b2fb49cc43` quickly becomes time consuming to do). With DBeaver, a developer can explore the database in a graphical way. DBeaver automatically executes the relevant queries to get the information displayed in DBeaver's GUI.
